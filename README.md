Многостраничное портфолио студента-разработчика, сочетающее функции визитной карточки, галереи проектов и учебного дневника.

## 📋 О проекте

Этот проект представляет собой личный веб-сайт, разработанный в рамках практических занятий по дисциплине "Фронтенд и бэкенд разработка". Сайт служит демонстрацией навыков веб-разработки и является основой для выполнения контрольных работ №2, №3, №4 и №5.

### 🎯 Основные функции

- **Визитная карточка** - представление студента и его навыков
- **Галерея проектов** - демонстрация учебных и личных работ
- **Учебный дневник** - отслеживание образовательного прогресса
- **Контактная форма** - возможность связи с автором

## 🚀 Технологии

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Фреймворк**: Bootstrap 5.3.2
- **Иконки**: Bootstrap Icons
- **Адаптивность**: Mobile-first подход
- **Валидация**: JavaScript формы
